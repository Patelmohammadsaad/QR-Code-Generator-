# QR Code Generator

A simple Python-based QR Code Generator built using the `qrcode` library.

This project takes text or a URL as input and generates a QR code image (`QRcode.png`).

## Features

* Generate QR codes from text or URLs
* Simple and beginner-friendly Python project
* Generates QR code as a PNG image
* Built using Python and the `qrcode` library

## Technologies Used

* Python
* Jupyter Notebook
* qrcode
* Pillow

## Installation

Clone this repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd QR-Code-Generator
```

Install the required library:

```bash
pip install qrcode[pil]
```

## How to Run

Open the `QRcode.ipynb` file in Jupyter Notebook or VS Code.

Run the cells and enter the text or URL you want to convert into a QR code.

The generated QR code will be saved as:

```text
QRcode.png
```

## Example

You can use the generator to create QR codes for:

* Websites
* Text messages
* Contact information
* Social media links
* Any other text or URL
